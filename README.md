## 📁 Repository Structure

The codebase is organized by topic, with each `.c` file implementing one concept:

| File | Description |
|------|--------------|
| `factorial_fibonacci.c` | Calculates factorial and Fibonacci series |
| `linked_list.c` | Implementation of a singly linked list |
| `math_equation.c` | Solves a given mathematical equation |
| `palindrome_string.c` | Checks whether a string is a palindrome |
| `pattern_matching.c` | Prints/solves number or star pattern problems |
| `queue.c` | Implementation of a Queue (enqueue, dequeue, display) |
| `searching.c` | Linear/binary searching algorithms |
| `stack.c` | Implementation of a Stack (push, pop, peek, display) |
| `tree.c` | Basic tree data structure operations |
| `bubble_sort.c` | Sorting an array using Bubble Sort |
| `insertion_sort.c` | Sorting an array using Insertion Sort |
| `palindrome_number.c` | Checks whether a number is a palindrome |
| `dynamic_array.c` | Dynamic array implementation using pointers |
| `recursive_fibonacci_factorial.c` | Factorial and Fibonacci using recursion |
| `sum_of_elements.c` | Calculates the sum of array elements |
